# Logisticus Route Estimate (iOS)

Prototype SwiftUI structure for a field app focused on renewable energy, heavy/oversize logistics. The app captures route estimates, clearance checks, and cost inputs for large, complex transportation jobs.

## Focus areas
- Renewable energy project logistics (turbines, blades, nacelles, transformers)
- Oversize / overweight routing constraints
- Underpass clearance measurement with camera support

## Modules
- App entry + navigation
- Estimate creation flow
- Route planning + stops
- Clearance checker
- Cost inputs + summary

## Notes
- This is a lightweight SwiftUI scaffold intended for UX and flow validation.
- Integrate real mapping, AR, and API services in later iterations.
